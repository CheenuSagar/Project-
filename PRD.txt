1. PRODUCT OVERVIEW & VISION
--------------------------------------------------------------------------------
ABES Academix is a progressive web and native Android mobile application 
designed specifically for the Master of Computer Applications (MCA) department 
at ABES Engineering College. 

The system provides live section schedule management (Sections III-A, III-B, III-C), 
automated pre-lecture alarm notifications, faculty proxy/substitution alerts, 
mentor attendance logging, official academic calendar integration, and an 
interactive syllabus tracker.

Key Value Proposition:
  - Zero Missed Classes: Proactive desktop, in-app, and native mobile alarms fire 
    5-15 minutes before every lecture.
  - Dynamic Section Selection & Switching: Instant 1-tap switching and persistent 
    section assignment across Section III-A (AB-207), Section III-B (AB-208), 
    and Section III-C (AB-209).
  - Multi-Role Portals: Unified access for Students, Teachers, Mentors, 
    Program Leaders (PL), and System Administrators.
  - Offline & Low-Bandwidth Support: Local storage caching paired with Capacitor 
    local background notifications ensures reminders work without internet access.

3. TECHNICAL ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
  - Frontend Framework: React 19, Vite 8
  - Styling & UI: Vanilla CSS Tokens, Glassmorphism, 20 Theme Engines, Lucide-React
  - Mobile Runtime: Capacitor 8 (@capacitor/android, @capacitor/local-notifications)
  - Backend & Database: Firebase v12 (Firestore Realtime Database & Firebase Auth)
  - Audio Engine: Web Audio API (Synthetic Double-Chime Synthesizer)
  - Storage & Cache: LocalStorage with automatic fallback and state persistence
